1. Version control fundamentals

Version Control System (VCS) : A VCS is a software which manages a repository (an evolving set of files) as a sequence, where each recorded state is called commits (revisions) which carries a set of metadata such as author, timestamp, message, etc. It provides a means to record every new/subsequent change, retrive old changes, compare the delta/difference between each subsequent change and enables simultaneous working on multiple parts of the repository and later merge the updates into one.
